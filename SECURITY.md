# Security policy

This policy applies to every Via-Tech Labs repository that does not have its own `SECURITY.md`.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting in the repository
(Security → Report a vulnerability), or write to info@via-tech.org with the project name and
"security" in the subject.

Useful to include: the version, your environment, steps to reproduce, and what an attacker could
do. Use made-up data in screenshots and logs, never real personal data.

We reply within 3 working days, agree on a fix date with you, and credit you in the release notes
unless you prefer otherwise.

## Supported versions

Only the latest release of each project gets security fixes.
