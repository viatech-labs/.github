### How we publish

- The code you can read is the code that ships. Velami builds are reproducible, and
  `npm run verify` compares an installed copy with the sources file by file.
- Tests, issues and screenshots use made-up data only.
- Vulnerabilities are reported privately, see the
  [security policy](https://github.com/viatech-labs/.github/blob/main/SECURITY.md).
